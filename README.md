# STV — просмотр рефлектограмм SOR на телефоне (iPhone / Android)

Веб-приложение для просмотра рефлектограмм OTDR в формате SOR (Telcordia SR-4731): график, таблица событий и участков (как на экране Viavi), потери, отражения, Span, пороги 1310/1550 нм и метка «Проверить соединение / возможен ремонт».

**Открыть:** https://panterkasmart-svg.github.io/stv-mobile/

- Файлы SOR **не покидают телефон**: всё читается и считается на устройстве, ничего не отправляется.
- Работает **без интернета** после первого открытия.
- Установка значка: iPhone — Safari → «Поделиться» → «На экран „Домой"»; Android — Chrome → меню → «Установить приложение».

## Что внутри

| Файл | Назначение |
| --- | --- |
| `index.html` | Приложение одним файлом (интерфейс + ядро расчётов) |
| `sw.js` | Офлайн-кэш (service worker) |
| `manifest.webmanifest`, `icon-*.png`, `apple-touch-icon.png` | Установка на главный экран |
| `source/stv-core.js` | Ядро: чтение SOR и расчёты — перенос настольной STV 0.4.0 (Python) |
| `source/app.html` | Исходник интерфейса |

Сверка ядра с настольной STV 0.4.0: 3 открытых образца и 768 полевых трасс Viavi SmartOTDR — 0 расхождений (178 654 значения).

Ограничения: `.msor` не поддерживается; файлы только читаются; потери участков у приборов Viavi показываются числом только при согласии с Total loss прибора (иначе «—» или «≈ оценка»).
